# CognitoLabs.ai for AI assistants

Connects your AI assistant to [CognitoLabs.ai](https://cognitolabs.ai): US hospital prices, payer rates, Medicare data and pricing studies. Remote MCP server, `https://mcp.cognitolabs.ai/mcp`, OAuth sign-in. Docs: https://docs.cognitolabs.ai

- **Claude Code:** `/plugin marketplace add CognitoLabsAI/cognitolabs-ai` then `/plugin install cognitolabs@cognitolabs`
- **Gemini CLI:** `gemini extensions install https://github.com/CognitoLabsAI/cognitolabs-ai`
- **Anything else:** add `https://mcp.cognitolabs.ai/mcp` as a remote MCP server.
